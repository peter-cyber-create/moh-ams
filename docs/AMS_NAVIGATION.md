# AMS navigation (UI)

Primary navigation is a **left sidebar** (not a top menu).

## Structure

| Item | Purpose |
|---|---|
| Home | What needs my attention? |
| Activities | List / create activities |
| Accountability | Financial cases |
| Compliance | Participation limits, overlaps, accountabilities |
| Reports | Four categories |
| More | Templates, Help (+ Admin/System for administrators) |

Activities stays active on register / edit / detail routes. Templates are under **More**, not Activities.

## Design

Simple government management UI. Does not reuse Inventory sidebar or branding.
