# AMS reports structure

Landing page (`/reports`) shows four categories only:

| Category | Purpose |
|---|---|
| Activities | Register / dates; activities missing a **report file** (not Accountability) |
| People | Participation by person; activity per person |
| Financial | Funding and amounts |
| Compliance | Links into Compliance domain: limits, pending/overdue accountabilities, overlaps (+ legacy 150+ list) |

Filters and Export live on individual report / Compliance pages — not on the landing page.

Accountability reports query the Accountability / Compliance domain. Do not confuse “missing activity report file” with Accountability cases.
