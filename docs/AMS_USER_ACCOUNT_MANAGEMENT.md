# AMS User Account Management

## Administration path

More → Administration → Users

## Create user

Fields: Full name, Email, Phone, Department, Role, Password, Confirm password, Status.

Passwords are hashed by Finance. AMS never receives or stores hashes.

## Edit

Name, phone, department, role (with confirmation), status.

## Deactivate / reactivate

Confirmation required. Inactive users cannot sign in. Historical Activities/Accountabilities remain.

Last active Administrator cannot be deactivated or demoted.

## Password reset (admin)

Set a new password only. Existing passwords cannot be viewed.

## Person link

If a Person is linked to the IdentityUser, the user detail shows the Person reference. Linking uses existing Wave 4 Person APIs.

## Self-service

More → My profile → Change password.
